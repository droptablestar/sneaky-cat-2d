# sneaky-cat-2d — Agent Context

2D side-scrolling stealth platformer in Godot 4. A cat moves through a room collecting
fish and reaching an exit door while avoiding enemies (dogs, humans) that patrol and chase.
The cat can hide in furniture/shelves to break line of sight and cancel chases.
